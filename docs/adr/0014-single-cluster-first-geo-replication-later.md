# 第一期只做单集群内的故障域分散，异地复制留待以后

第一期不做跨城市的异地复制，也不做定期异地备份。数据的副本或纠删码碎片只在单个集群内按 Failure Domain 分散。因此单盘、单机、单可用区故障可以承受；整个集群所在地发生灾难，或整个集群被误删时，服务中断，数据可能丢失。之所以接受这个风险，是因为异地复制涉及冲突处理和切换流程，是一个独立的大工程，第一期优先保证单集群稳定。

## Considered Options

- **异地自动复制**：最多丢失几分钟的数据，但机器和存储翻倍，并且需要设计双集群的冲突处理与切换流程。
- **定期异地备份**：成本较低，但最多丢失一个备份周期的数据，几百 TB 级的恢复需要数天。

## Consequences

- 为以后的异地复制保留扩展点：每次 Object 提交都有全局严格递增的 Generation（见 ADR 0008），将来可以按 Generation 顺序增量地把变更发往异地集群，不需要改动现有的数据模型。
