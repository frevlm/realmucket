# Client SDK 的兼容范围由开发团队逐版决定；已存数据永远可读

Client SDK 不承诺固定的兼容期。每次发布服务端时，由开发团队手动决定仍然支持哪些 SDK 版本，太旧的版本要求业务方升级。已经存入的数据则没有任何例外：无论服务端升级多少次，以前写入的 Object 都必须能读出来。因为程序库太旧时业务方可以升级补救，而数据读不出来时业务方无从补救。

## Considered Options

- **永远兼容所有 SDK 版本（S3 式）**：业务方完全不用关心升级，但服务端要永久保留所有旧的处理逻辑。
- **固定保证最近 N 个大版本、每个至少 M 个月**：对业务方可预期，但约束了开发团队的发布节奏。

## Consequences

- 兼容范围是手动决定的，所以服务端必须能看到每个 SDK 版本的实际调用量，作为决策依据；也必须能配置“最低支持的 SDK 版本”，对更旧的版本返回明确说明“需要升级到哪个版本”的错误，而不是出现难以理解的失败。
- “数据永远可读”依赖 ADR 0006 的自描述盘上格式：新版本必须保留所有历史 Chunk 格式的读取能力，只有写入格式可以更新。
